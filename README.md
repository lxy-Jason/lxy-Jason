做个人 Agent 与数据底座。

## 在做什么

- **个人 Agent** — 跨设备的工作台。人不在电脑前，也能把事情说清楚、做完。
- **数据底座** — 笔记、阅读和上下文收成自己的 hub，供 Agent 取用。Context Hub 是这层底座上的一块。
- **译读** — 用喜欢的中文小说学英语。

## 产品与站点

- [Agent Blog](https://agent-blog.top) — 可引用的公开站点。笔记、案例和产品从这里进入。
- [译读 TransRead](https://agent-blog.top/products/transread/) — iOS 阅读器。AI 翻译 EPUB / TXT，原文、对照、译文、对话四种读法。
- [Agents Anywhere](https://agents-anywhere.com) — 在桌面、手机和 Web 使用你的 AI Agent。
